# Задание 5. Разработка cutover-плана

## Обоснование выбора стратегии миграции

Выбран подход Parallel Run (параллельный запуск старой и новой системы) как наиболее подходящий для сценария.
## Преимущества
- минимальный риск для бизнеса — старая система остаётся рабочей;
- возможность поэтапного переключения пользователей;
- прямое сравнение результатов работы систем;
- плавное наращивание нагрузки на новую платформу;
- сохранение работоспособности при частичных сбоях новой системы.

## Ограничения

- двойная нагрузка на инфраструктуру (ресурсы старой и новой систем);
- сложность синхронизации данных между системами;
- необходимость поддержки двух систем в период параллельной работы;

## Ожидаемые результаты

- современная масштабируемая архитектура на основе микросервисов;
- централизованное управление API через Gateway;
- высокая доступность и отказоустойчивость системы;
- чёткое разделение ответственности между сервисами;
- отовность к дальнейшему развитию и добавлению новых функций.
